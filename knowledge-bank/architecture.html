System Architecture Strategy

Start as a modular monolith for delivery speed, then extract microservices as complexity and scale justify the split.

Flow Diagram

Decisions

  • Use FastAPI as system orchestrator.
  • Keep Spring Boot optional for phase-2 policy complexity.
  • Tenant isolation via `tenant_id` and policy-scoped execution.
  • One bot identity per tenant with encrypted credentials.
  • Event pipeline for moderation summaries and behavior scoring.

Tenant Isolation Controls

  • Global tenant context middleware
  • Row-level filters and table indexes
  • Redis key namespacing by tenant
  • Policy boundary checks per request

Reliability Controls

  • Idempotency keys for mutating actions
  • Retry + backoff on Discord failures
  • Circuit breaker on rate-limit spikes
  • Dead-letter queue for failed jobs

Migration Path

  • Modular monolith in v1
  • Split AI/Policy/Discord services incrementally
  • Contract tests before each extraction
  • No early microservice tax
