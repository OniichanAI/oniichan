# Knowledge Bank

Multi-page visual documentation site for the project.

## Entry Point

- Open `index.html`

## Pages

1. `index.html` - high-level overview
2. `docs-library.html` - map of all Markdown files
3. `architecture.html` - architecture and scale path
4. `backend-ai.html` - backend, Discord, AI orchestration, RAG
5. `frontend.html` - Angular + Tailwind implementation guide
6. `security-data-ops.html` - auth, security, data, DevOps
7. `roadmap-todo.html` - timeline and searchable task tracker
8. `interview.html` - remaining deep-dive interview questions

## UX Features

1. Focus mode toggle
2. Collapsible detail sections
3. Visual progression bars and timelines
4. Searchable implementation task list
