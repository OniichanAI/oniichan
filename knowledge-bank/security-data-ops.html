Security, Data Model, and Operations

Secure-by-default v1 with a clear path for enterprise hardening later.

Authentication

  • Discord OAuth only in v1
  • Short-lived access token
  • Rotating refresh token
  • Session revocation support

Authorization

  • RBAC baseline
  • Policy checks for context-aware decisions
  • Auto role mapping with manual override
  • Protected entities enforcement

Audit Requirements

  • Log actor, prompt, intent, confidence
  • Store policy decision traces
  • Store execution receipts
  • Immutable append-only ledger

Database Recommendation

Primary: PostgreSQL

Vector: `pgvector` in same DB for v1

Cache/Queue: Redis

Object storage: MinIO local now, S3-compatible later

Infrastructure Plan

Start local with Docker Compose and move to AWS or Hetzner once budget unlocks. Keep components cloud-agnostic.

Risk Control Matrix

Risk Default Policy Execution Rule
Low Read/summary actions Auto execute if confidence high
Medium Role/channel permission edits Confirm when confidence medium
High Kick/ban/delete/mass actions Mandatory confirmation + full audit trace

DevOps Baseline

  • GitHub Actions CI/CD
  • dev/staging/prod environments
  • Trunk-based + feature flags
  • Auto rollback triggers

Observability Stack

  • OpenTelemetry instrumentation
  • Prometheus + Grafana metrics
  • Loki logs and trace tooling
  • Domain metrics: tool success, confidence spread, false positives
